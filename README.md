## Description 
This project uses React.js with three.js and blender for 3D modeling. 

## Prerequisites
Install react-three dependencies  
```javascript
npm install
```
Run the project locally  
```javascript
npm run dev
```

## Inspiration 
I have always wanted to make myself a really cool portfolio. After I saw [Bruno Simon Car](https://2019.bruno-simon.com/), I really wanted to make my portfolio interactive and three-dimensional. In 2025 spring, I started watching [Blender Guru's](https://www.youtube.com/@blenderguru) donut tutorial and make my first donut. You can see my cute and yummy donut in my [blender_donut repo](https://github.com/evalee20000831/blender_donut). 

After getting some hands-on experience with Blender, I saw [Andrew Woan](https://www.youtube.com/watch?v=AB6sulUMRGE) released a completely FREE 9-hr tutorial video on [sooahs-room-folio](https://www.sooahs-room-folio.com/), teaching how to make a room portfolio from scratch for beginners! I followed along the video and make my own meshes in blender around 2025 winter for a few months (👈 I definitely spend more than 9 hours watching this 🐐) 

For the coding part, I switched from three.js to react js with three.js, simply because I want to learn how to use React 🦄
